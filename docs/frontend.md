# SQNote フロントエンド設計

## 概要

v1 はサーバーサイドレンダリングの PHP 実装。将来的に React / React Native への移行を見越した設計とする。

## 画面構成

```
/                     → ノート一覧（最終更新順）
/notebooks            → ノートブック一覧
/notebooks/{id}       → ノートブック内のノート一覧
/notes/new            → ノート作成
/notes/{id}           → ノート詳細表示
/notes/{id}/edit      → ノート編集
/tags                 → タグ一覧
/tags/{name}          → タグで絞り込んだノート一覧
/search               → 全文検索結果
/import               → インポート画面（enex ファイルアップロード）
/export               → エクスポート画面
```

## レイアウト

+----------------------------------------------------------+
| [SQNote]              [検索ボックス]          [設定]       |
+------------------+---------------------------------------+
|                  |                                       |
| [ノートブック一覧]  |  ノート一覧 or 詳細                    |
|                  |                                       |
| - すべてのノート   |                                       |

| - ノートブック B   |                                       |
|                  |                                       |

```
+----------+-------------------+-----------------------------+
| サイドバー | ノートリスト       | ノート本文                   |
| (ノート   | (タイトル・更新日  | (表示 or 編集)               |
|  ブック   |  プレビュー一覧)   |                             |

+----------+-------------------+-----------------------------+
```

## 主要画面の仕様

### ノート一覧

- 最終更新日時降順でリスト表示
- 1件あたり: タイトル・ノートブック名・タグ・更新日時・本文プレビュー（冒頭100文字）を表示
- ページネーション: 20件/ページ
- クリックでノート詳細を表示

### ノート詳細

- タイトル・本文（HTML レンダリング）・タグ・更新日時・ソース URL を表示
- 添付ファイルがある場合はサムネイルまたはファイルリストを表示
- 編集ボタンで編集画面へ遷移
- 削除ボタンでソフトデリート（確認ダイアログあり）

### ノート編集

- タイトル: テキスト入力
- 本文: Markdown エディタをデフォルト表示。`content_type = 'html'` のノート（インポートデータ等）は WYSIWYG エディタで表示・編集
- タグ: タグ入力（既存タグのオートコンプリート）
- ノートブック: セレクトボックス
- 添付ファイル: ドラッグ＆ドロップまたはファイル選択でアップロード
- 保存ボタン（Ctrl+S / Cmd+S ショートカット対応）

### 検索

- ヘッダーの検索ボックスからクエリを入力
- タイトル・本文を対象に検索
- ノートブック・タグでの絞り込みフィルターを表示

## WYSIWYG エディタ

v1 実装では [Quill.js](https://quilljs.com/) または [TipTap](https://tiptap.dev/) を使用する。
`data-format.md` に定義した HTML サブセットのみ出力するよう設定する。

Markdown モードでは CodeMirror または SimpleMDE を使用する。

## 認証

BASIC 認証でアプリ全体を保護する。PHP 実装では Apache / Nginx の BASIC 認証、またはアプリ内で `$_SERVER['PHP_AUTH_USER']` / `$_SERVER['PHP_AUTH_PW']` を確認する。

認証情報は環境変数または設定ファイルで管理する。

```
SQNOTE_BASIC_USER=admin
SQNOTE_BASIC_PASS=（パスワード）
```

## フロントエンド技術スタック（v1）

| 役割 | 技術 |
|---|---|
| テンプレートエンジン | PHP（素の PHP テンプレートまたは Twig） |
| CSS | CSS カスタムプロパティを使ったシンプルなスタイル |
| JS | バニラ JS（最小限）+ エディタライブラリ |
| ビルドツール | なし（v1 はシンプルに） |

## 将来の React 移行に向けた考慮点

- API を REST で分離しているため、フロントエンドを SPA に差し替えるだけで移行可能
- `/api/v1` のエンドポイントを変えずに React アプリをデプロイできる
- 認証を BASIC 認証から JWT 等に変更する際は API 仕様を v2 にバンプする
