# 閲覧で、本文をクリックしたら編集モードへ移行する

## 概要
ノート詳細画面（`/notes/{id}`）の本文エリアをクリックすると、編集画面（`/notes/{id}/edit`）へ遷移するようにした。ヘッダーの「編集」ボタンを押すのと同じ操作を、本文クリックでも行えるようにして編集開始の導線を短くする。

## 実装内容
- `templates/note/show.html.twig`
  - 本文の `<div class="note-body">` に `id="note-body"` を付与。
  - `<script>` ブロックに本文クリック用のイベントハンドラを追加。クリック時に `/notes/{{ note.id }}/edit` へ遷移する。ただし本文内のリンク（`<a>`）・画像（`<img>`）をクリックした場合は遷移せず本来の動作を優先する。
- `public/assets/css/app.css`
  - `.note-body` に `cursor: text;` を追加し、テキスト編集可能な領域であることを視覚的に示す。

## 使い方
- ノート詳細画面で本文の任意の場所をクリックすると、そのノートの編集画面へ移動する。
- 本文中のリンクや画像をクリックした場合は、これまで通りリンク遷移・画像表示が行われ、編集画面へは移動しない。
- 添付ファイルセクション（`.note-attachments`）はクリックによる遷移の対象外。

## 技術的な補足
- 遷移先 URL は Twig テンプレート内で `{{ note.id }}` をそのまま JS 文字列に埋め込む。既存の `deleteNote('{{ note.id }}')` と同じ実装パターン。
- リンク・画像のガードは `e.target.closest('a, img')` で行う。クリック対象またはその祖先に `<a>` / `<img>` があれば遷移をスキップする。
- `cursor: text` は本文がテキストとして扱える領域であることを自然に示す指定で、機能自体には影響しない。
